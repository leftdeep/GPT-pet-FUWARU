# 目录与清理说明

当前发布版本为 0.50（由 pet-release.json 指定实际目录），当前人物使用 `assets/imported/dragon-girl-calibrated` 的十一段动作，默认及回退使用 `assets/dragon-girl-0.40`。正式程序、素材和启动入口见根目录 [README](../README.md)。

`animation/` 保留原始动作视频；`assets/` 保留正式素材、角色设计和转换记录；`local-data/` 保存用户设置、位置和成长记录。运行使用 `runtime/ffmpeg.exe` 和 .NET 10 Desktop Runtime，开发 SDK 位于 `tools/dotnet/`。

旧待机切换演示、随机走路试验、测试截图及临时运行数据已经清理。`scripts/` 保留启动、发布校验、独立原生验证和通用 MOV 转换脚本；`tests/` 保留维护程序所需的自动检查源代码。

升级前数据和源码备份、历史发布记录及旧版发布快照仍保留；它们不参与当前运行。`dsh-pet/` 是独立的参考项目。

2026-10-06 已删除 `lib` 中 0.40 之前的运行副本、临时发布目录和根层旧程序，以及 `assets/converted/dragon-girl-0.30`、`dragon-girl-0.31` 两套重复素材。`lib/0.40` 与 `lib/0.41` 保留。旧文档中的旧运行目录路径仅作为历史记录，详见 [检查报告](项目冗余检查-2026-10-06.md)。

0.42 按 [结构优化记录](结构优化-2026-10-06.md) 拆分窗口职责；原生检查从 src 移入 tests/GptSpritePet.NativeTests。版本只在 Directory.Build.props 定义，lib 中新发布使用唯一目录，pet-release.json 指向当前/上一版本。运行包通过该标记找到素材和 FFmpeg，不需要附带 build.ps1、开发 SDK、测试或 DSH 项目。

0.50 将四个功能窗口合并为 `PetControlWindow` 和四个独立内容页；重置公告警告仍是人物旁的气泡。删除旧 0.30–0.36 素材包、未校准导入包、两个旧贴边姿势、重复参考图、0.41 的临时界面预览，以及当前导入配方不再使用的 85 个缓存目录。当前十一项动作的缓存与两项完整视频的归一化缓存仍保留。原视频专用空间仍为 `animation/`，审核基准、角色设计图、用户存档与 DSH 项目保留。删除清单见 [素材清理记录](素材清理-0.50.json)。
