# 项目目录

| 路径 | 用途 |
|---|---|
| src、tests | 程序源码及回归检查 |
| scripts、build.ps1 | 启动、构建、打包、解码器构建与动作转换 |
| assets/imported/dragon-girl-calibrated | 现用九动作，13 个 640 视频分段及清单 |
| assets/edge-peek | 现用贴边探头图片 |
| animation | 九个原始 MOV、动作配方与校准记录 |
| dsh-pet | 保留的 DSH 参考项目，独立于芙哇噜运行 |
| assets/dragon-girl-calibration-base、assets/authoring-baselines | 后续动作制作与原 MOV 重建所需基准，不随便携包发布 |
| runtime | 本地完整 FFmpeg，供播放及新增动作编码 |
| tools | 本地 .NET SDK、NuGet 依赖 |
| lib、pet-release.json | 当前已编译发布及一个上一版本 |
| local-data | 个人设置、成长记录、用量和公告数据 |
| output | 按需生成的转换预览及发布产物 |
| verification | 当前版本的检查结果与清理记录 |
| .github、skills | GitHub 发布工作流及项目动作导入流程 |

正式下载包内使用精简播放解码器。制作新动作继续使用本地完整编码器。旧 0.40 回退素材已移除，DSH 项目保留。
