# 交互精简与自启动（0.52）

- 移除双击人物打开设置；设置继续通过人物或托盘的右键菜单打开。
- 移除人物说话气泡及相关计时器、问候、点击文案、升级通知与低额度文字提醒。单击互动动作和成长计数继续保留。
- Token／额度悬浮卡、颜色提示、详情页、重置公告窗口保持原有功能。
- 设置 → 桌面行为新增「开机自启动（登录 Windows 后）」。勾选或取消后点击「应用设置」生效，恢复默认值会将开关设为关闭，应用后移除启动项。

自启动使用当前用户的 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，值名由 Fuwaru 与项目绝对路径摘要组成，只管理当前项目。Windows 注册项是开关状态来源；默认没有启动项，应用其他设置不会创建启动项。命令使用带引号的完整路径、隐藏 PowerShell 和现有 scripts/launch-dragon-girl.ps1，读取 pet-release.json 启动当前发布，不固定某个 lib 版本目录。无需管理员权限，登录后正常恢复保存的位置和素材。

写入失败会在设置页显示错误，避免显示“设置已应用”。本次验证使用模拟启动项完成开关、重新读取、关闭、过期命令修正与权限错误测试，不实际启用自启动。旧 settings.json 中的 UsageLowAlerts、GrowthNotifications 字段保留兼容，不再控制说话气泡。

验证结果见 verification/interaction-startup，包含核心检查、发布流程检查、原生窗口检查与截图。正式素材继续采用已生成的 640／CRF40 动作。
