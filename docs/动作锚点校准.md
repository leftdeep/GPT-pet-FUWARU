# 正式点击动作的色调与锚点校准

开心跳跃和害羞已确认采用相同的颜色参考与头部/双脚校准；正式配置只有 `animation/actions.json`。两者位于「点击互动」，菜单顺序为开心跳跃、害羞，均完整播放一次后返回待机。当前程序负责该组的点击随机触发，本次只整理素材和转换工具，不修改触发代码。

双击 `查看锚点对比.cmd`。三列为待机基准、已统一色调的原动作、正式锚点动作；视频完整展示进入、动作与返回，锚点可关闭，详情中放大首尾头部/双脚。青色十字是待机参考，橙色圆圈是人工标定的站姿点，仅在动作首尾各五帧显示，不是跳跃中的实时跟踪。

## 文件与固定入口

| 文件/目录 | 用途 |
| --- | --- |
| `animation/*.mov` | 原视频，全部保留 |
| `animation/actions.json` | 唯一正式动作清单、颜色/锚点配方及审核哈希 |
| `animation/anchor-calibration.json` | 384×384 站姿鞋底标注、头部区域与颜色参考文件/哈希 |
| `assets/dragon-girl-calibration-base` | 已确认的七段成品和两段校准前颜色参考；参考视频不加入动作菜单 |
| `assets/imported/dragon-girl-calibrated` | 安装与播放的七段正式动作 |
| `output/.cache/animation-import` | 按源、配方、处理模式及工具哈希复用的缓存 |
| `output/anchor-preview` | 当前完整比较视频、放大图和报告 |
| `verification/actions-20261007` | 校准前配置/设置/素材、已确认预览，以及清理记录 |

```powershell
# 生成并验证正式素材，暂不安装
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/import-pet-actions.ps1
# 安装正式素材，保留位置、设置和成长存档
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/import-pet-actions.ps1 -Apply
# 重建完整比较，不修改设置或重启桌宠
python scripts/preview-pet-actions.py
```

导入与转换仅需标准库和 FFmpeg；完整比较使用 NumPy/Pillow。原 384 审核 WebM 与当时确认预览逐文件核对 SHA-256，保留作为校准基准。2026-10-10 已授权升级为 640/CRF40：通过冻结质量档案从原 MOV 应用同一配方后一次压缩，正式安装直接复制新成品，不重复校色或累加锚点变换。

## 已确认的参数与效果

RGB 通道使用固定单调曲线、黑白端点、33³ LUT 和鲜艳色保护，改善头发/衣服冷暖与明暗；不改变 Alpha，不把眼睛、腮红和爱心强制变成待机颜色。完整配方保存在两个动作的 `conversion.colorCorrection`，安装时作为审核记录保留，不重复执行。

双脚鞋底接触区域中心经首尾站姿放大检查，标注精度约 ±1 像素。两脚中点决定位置与脚底基准，头部参考区域 `[135,153,115,43]` 的不透明上部轮廓中心决定横向对齐；该点不等于眼睛/脸部姿态中心。头部使用首尾十帧平均，动作中段不重算比例。

| 动作 | 帧数 / 时长 | 横向比例 | 高度 | 脚底固定偏移 |
| --- | --- | ---: | ---: | ---: |
| 开心跳跃 | 95 / 3.958 秒 | 104.95% | 100% | +0.5 px |
| 害羞 | 144 / 6.000 秒 | 103.65% | 100% | +0.5 px |

固定仿射变换为 `x' = sx*x + shear*y + tx`、`y' = y + dy`；Happy 的倾斜修正 -0.01547，Shy +0.03225。高度不缩放，也不逐帧将脚钉在地面，任意真实跳跃纵向位移保持原样。全动作使用同一组参数；两脚中点与头部横向中心映射到基准，脚间距、脸部角度和表情仍保留自然姿态。独立制作候选时采用预乘 Alpha、固定 cubic 仿射插值、VP9 无损编码和计划 Alpha 逐字节检查；插值与 RGB/YUV 4:2:0 转换仍可能带来少量像素变化。

## 成品审核与避免重复处理

两个动作采用 `reviewedFinal: true`，其 `reviewed` 同时校验原 MOV 哈希、成品 WebM 哈希和含颜色/锚点的完整配方指纹。任意源或校准参数变化都会停止，避免静默退回未校准视频。已经处理完的成品不允许再同时启用 `colorFromReviewed` 或 `anchorFromReviewed`。缓存键也包含处理模式，防止成品复用与候选变换取到同一缓存结果。

制作新候选时，普通 MOV 先按 348.333 像素共同站立高度、576 脚底线和固定角色区域标准化；以干净站姿检查颜色、头部和鞋底标注，源构图变化后必须重新测量。独立配置可用 `colorFromReviewed` 校色，再从颜色参考用 `anchorFromReviewed` 校准，输出到不同的 `assets/imported` 子目录。检查后将确认成品和审核指纹登记到正式基准与清单；不能只删除 `reviewedFinal` 绕过复核。

所有新输出检查全帧尺寸、真实时间戳、Alpha、边界和内存预算，清单最后原子提交。正式两个动作共 239 帧，透明效果与已确认计划一致；其他五段动作、走路校准和过渡字段保持原值。重复运行复用缓存，名称/分组变动无需编码。
